# Guidelines: Step 3, Drift schema (first slice)

Audience: `model-implementer`. Follow literally. Stop and report on conflict with the code.

## Allowed write paths

- `pubspec.yaml`, `pubspec.lock` (add deps only)
- `lib/core/database/**` (new files)
- `test/database/**` (new files)

Do not touch: `lib/features/**`, `lib/core/di/**`, `lib/core/database/objectbox_service.dart`, `lib/core/preferences/**`, `ios/**`, `android/**`, `docs/**`. Do not commit.

## Steps

1. Dependencies. Read pub.dev for `drift`, `drift_flutter`, `drift_dev`. Pick latest stable published ≥14 days ago. Add:
   - `dart pub add drift drift_flutter`
   - `dart pub add dev:drift_dev dev:build_runner` (build_runner already present; skip if so)
   - Do not add `sqlite3_flutter_libs` unless `drift_flutter` README says it is required.
   - Record chosen versions in your report.

2. Files to create:
   - `lib/core/database/app_database.dart`: `@DriftDatabase(tables: [...])` class `AppDatabase`. Constructor takes `QueryExecutor` (for tests). Default factory `AppDatabase.open()` uses `driftDatabase(name: 'medify_v2')` from `drift_flutter`.
   - `lib/core/database/tables/profiles.dart`
   - `lib/core/database/tables/medicines.dart`
   - `lib/core/database/tables/schedules.dart`
   - `lib/core/database/tables/occurrences.dart`
   - `lib/core/database/tables/achievements.dart`
   - `lib/core/database/tables/settings.dart`
   - `lib/core/database/tables/installation_metadata.dart`
   - `lib/core/database/enums.dart`: Dart enums for status and types. Use Drift `textEnum<T>()`.
   - `test/database/app_database_test.dart`: in-memory `NativeDatabase.memory()`.

3. Overrides in `AppDatabase`:
   - `beforeOpen`: run `PRAGMA foreign_keys = ON`.
   - `schemaVersion => 1`.

4. Table mapping (legacy → v2). Column names snake_case via Drift defaults.

   `profiles`:
   - `id` int autoincrement PK
   - `name` text not null
   - `relation` text nullable
   - `date_of_birth` dateTime nullable
   - `role` textEnum `ProfileRole` (patient, caregiver), not null
   - `color_value` int not null
   - `avatar_emoji` text nullable
   - `is_archived` bool default false
   - `created_at`, `updated_at` dateTime not null

   `medicines` (legacy `MedicineModel`):
   - `id` PK; `profile_id` int FK → profiles.id, not null
   - `name` text not null
   - `medicine_type` textEnum `MedicineType` not null
   - `dose_amount` real not null; `dose_unit` text not null (legacy `dosage` string kept as `dose_label` text not null)
   - `intake_timing` textEnum `IntakeTiming` not null
   - `notes`, `photo_path`, `voice_note_path` text nullable
   - `total_quantity`, `current_quantity` real nullable
   - `refill_remind_days` int nullable; `last_refill_date` dateTime nullable
   - `state` textEnum `MedicineState` (active, paused, finished) not null
   - `stop_reason` text nullable
   - `created_at`, `updated_at` not null
   - CHECK: `current_quantity IS NULL OR current_quantity >= 0`

   `schedules` (replaces legacy `reminderTimes` + `daysOfWeek` + `endDate`):
   - `id` PK; `medicine_id` FK → medicines.id not null, onDelete cascade
   - `time_of_day_seconds` int not null, CHECK between 0 and 86399
   - `weekdays_mask` int not null default 127 (bit 0 = Monday). CHECK between 1 and 127
   - `start_date` dateTime not null; `end_date` dateTime nullable
   - `notify` bool default true
   - `missed_window_minutes` int not null default 60, CHECK > 0
   - `is_active` bool default true

   `occurrences` (replaces `MedicineLogModel`):
   - `id` PK; `profile_id` FK → profiles.id not null; `medicine_id` FK → medicines.id not null; `schedule_id` FK → schedules.id not null
   - `scheduled_at_utc` dateTime not null (store UTC)
   - `local_date` text not null (`YYYY-MM-DD`, snapshot)
   - `status` textEnum `OccurrenceStatus` (scheduled, taken, skipped, missed) not null default scheduled
   - `taken_at_utc`, `snoozed_until_utc` dateTime nullable
   - `skip_reason` text nullable
   - `actor_profile_id` FK → profiles.id not null
   - `dose_snapshot_amount` real not null, `dose_snapshot_unit` text not null
   - `created_at`, `updated_at` not null
   - UNIQUE (`schedule_id`, `scheduled_at_utc`)
   - CHECK: `(status = 'taken') = (taken_at_utc IS NOT NULL)`

   `achievements`:
   - `id` PK; `profile_id` FK not null; `type` textEnum `AchievementType` not null; `progress` int not null default 0; `unlocked_at_utc` dateTime nullable
   - UNIQUE (`profile_id`, `type`)

   `settings` (typed key/value):
   - `key` text PK; `value` text not null; `value_type` textEnum `SettingType` (bool, int, string, enumName) not null
   - Keys seeded later; no seed rows in this slice.

   `installation_metadata`:
   - `id` int PK fixed to 1, CHECK id = 1
   - `installation_id` text not null (UUID v4 string, generated by caller, not here)
   - `lifecycle` textEnum `LifecycleState` (fresh, v2_created, complete) not null
   - `created_at_utc` dateTime not null

5. Enums in `enums.dart`: `ProfileRole`, `MedicineType`, `IntakeTiming`, `MedicineState`, `OccurrenceStatus`, `AchievementType`, `SettingType`, `LifecycleState`. Values use PascalCase in Dart. Legacy enum definitions are in `lib/features/medicines/domain/entities/` (check `MedicineIntakeTiming`, medicine type enum); copy value names, do not import legacy files.

6. Run generator: `dart run build_runner build --delete-conflicting-outputs`. Commit nothing. Save schema dump: `dart run drift_dev schema dump lib/core/database/app_database.dart lib/core/database/drift_schemas/` (check `drift_dev schema --help` for exact syntax).

7. Tests in `test/database/app_database_test.dart`, using `NativeDatabase.memory()` and `AppDatabase(executor)`:
   - FK on: insert medicine with missing profile_id → throws.
   - CHECK: occurrence `status='taken'` with null `taken_at_utc` → throws.
   - UNIQUE: two occurrences same schedule_id and scheduled_at_utc → second throws.
   - Enum round trip: insert medicine with `MedicineType.syrup`, read back equal; raw SQL shows text `'syrup'`, not `1`.
   - Cascade: delete medicine removes its schedules.
   - Cross-patient guard: schedule for medicine owned by profile A, occurrence with profile B for that medicine → allowed only if design says so. Decision: occurrences.profile_id must equal medicines.profile_id. Enforce with a trigger `BEFORE INSERT ON occurrences` that RAISE(ABORT) on mismatch. Add a test for it.

## Verification

Run in this order, stop on first failure:
- `dart pub get`
- `dart run build_runner build --delete-conflicting-outputs`
- `dart format --set-exit-if-changed lib/core/database test/database`
- `flutter analyze lib/core/database test/database`
- `flutter test test/database`
- `git status --short` and `git diff --stat`

## Stop and report if

- `drift_flutter` requires a different platform setup than described.
- Any existing test or analyzer error appears outside the allowed paths.
- A table field needs a decision not listed here (report it, do not guess).
